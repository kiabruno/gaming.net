GAMING.LUXUS Regeln

Unsere Regeln:

Allgemeine Regeln

1. Jeder Spieler muss die Serverregeln beachten.

2. Unwissenheit über die Regeln schützt nicht vor einer Strafe.

3. Respektvoller Umgang ist Pflicht.

4. as Ausnutzen von Regel-Lücken ist nicht erlaubt.

5. Anweisungen des Serverteams sind zu beachten.

6. Das absichtliche Provozieren anderer Spieler ist verboten.

7. Falsche Meldungen gegen andere Spieler sind nicht erwünschd.

8. Das Umgehen von Strafen ist verboten

9. Das Ausgeben als Teammitglied ist verboten.

10. Entscheidungen des Teams dürfen nicht absichtlich sabotiert werden.

Chat & Kommunikation

1. Kein Spam, und kein Kein Flooding.

2. Keine Chat-Nachrichten ausschließlich in Großbuchstaben, wenn sie andere stören.

3. Keine Beleidigungen.

4. Kein Mobbing, und keine Drohungen.

5. Keine diskriminierenden oder menschenverachtenden Äußerungen.

6. Keine unangemessenen sexuellen Inhalte.

7. Keine persönlichen Daten anderer veröffentlichen.

8. Keine unnötigen Streitigkeiten im öffentlichen Chat.

9. Keine absichtlichen Provokationen.

10. Keine irreführenden Nachrichten, die andere Spieler täuschen sollen.

PvP Server

1. PvP darf nur dort stattfinden, wo es erlaubt ist.

2. Keine Spawn-Kills.

3. Keine Fallen, die gegen die jeweiligen PvP-Regeln verstoßen. (Gehe auf das Ausfühliche Regeln werk(Jeder PvP server hat seine eigende regeln!))Ausfühliches Regel Werk

4. Kein Ausnutzen von Bugs im Kampf.

5. ine unerlaubten PvP-Clients oder Cheats.

Handel & Wirtschaft

1. Betrug beim Handel ist verboten.

2. Absprachen beim Handel müssen eingehalten werden.

3. Keine Gegenstände duplizieren.

4. Keine illegal erworbenen Items verkaufen.

5. Keine absichtliche Manipulation der Serverwirtschaft.

6. Keine Fake-Shops oder irreführenden Angebote.

7. Echtgeld handel ist strengstens verboten.

Bugs & Exploits

1. Bugs dürfen nicht absichtlich ausgenutzt werden.

2. Gefundene schwerwiegende Bugs sollten dem Team gemeldet werden.

3. Keine Item-Duplikations-Bugs.

4. Keine Exploits zur Umgehung von Schutzsystemen.

5. Keine Tricks, um Serverbeschränkungen zu umgehen.

Cheats & unerlaubte Mods

1. Keine Cheats.

2.Keine X-Ray-Software.

3. Keine KillAura.

4. Keine Fly-Hacks.

5. Keine Speed-Hacks.

6. Keine unerlaubten Auto-Clicker, falls ihr diese verbieten wollt.

7. Keine Programme, die einen unfairen Vorteil verschaffen.

8. Erlaubte Mods können in einer separaten Liste aufgeführt werden.

Accounts

1. Das Umgehen eines Banns mit einem Zweitaccount ist verboten.

2. Das Ausgeben als eine andere Person ist verboten.

3. Das Ausgeben als Teammitglied ist besonders streng verboten.

4. Das absichtliche Erstellen vieler Accounts zur Umgehung von Regeln ist verboten.

5. Das Benutzen eines zweiten Acchaunts muss beantragt werden! (Ansonsten ist es verboten.)

Werbung

1. Keine Werbung für andere Minecraft-Server ohne Erlaubnis.

2. Keine Werbung für fremde Discord-Server ohne Erlaubnis.

3. Keine Spam-Werbung im Chat.

4. Keine unerlaubte Werbung über private Nachrichten.

5. Keine Links zu schädlichen oder betrügerischen Websites.
